# lone-master-version
Lone Client is a clean, customizable PvP HUD client for Fabric 1.21.9-1.21.11. 35 modules, item physics, shulker tooltips, FPS boost, natural cape sway, skins and capes, a snowy title screen and a built-in texture pack manager. Every module has its own settings, plus a drag-and-drop HUD editor. Press Right Shift in game.
